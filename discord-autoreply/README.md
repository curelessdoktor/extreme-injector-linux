# Discord Auto-Reply

A desktop app that automatically replies on Discord when someone **replies to your messages**. The reply is generated by AI (via **LM Studio**) to say you're not at your computer, with a black & white GUI, rounded corners, and smooth animations.

## Requirements

- **Python 3.10+**
- **Discord token** (user or bot token)
- **LM Studio** running locally with a model loaded and the **Local Server** started (default: `http://localhost:1234/v1`)

## Setup

1. Install dependencies (use a virtual environment if your system restricts pip):

   ```bash
   cd discord-autoreply
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

2. In **LM Studio**: load a model and start the **Local Server** (often under the “Local Server” or “API” tab).

3. Get a **bot token** (no personal account token needed):
   - Go to [Discord Developer Portal](https://discord.com/developers/applications) → New Application → Bot → Reset Token / Copy.
   - Invite the bot to your server (OAuth2 → URL Generator → scopes: `bot`; permissions: *Read Messages/View Channels*, *Send Messages*, *Read Message History*).
   - The app will auto-reply when someone **replies to a message the bot sent**. Optionally set `DISCORD_AUTO_REPLY_TOKEN` in your environment so you never paste the token into the app.

## Run

```bash
# If you used a venv:
.venv/bin/python app.py
# Otherwise:
python app.py
```

- Enter your **bot token** (or set `DISCORD_AUTO_REPLY_TOKEN` and leave the field empty) and the **LM Studio API URL** if needed (default `http://localhost:1234/v1`).
- Click **Start**. When someone **replies to a message your bot sent**, the app will ask LM Studio for an “away” message and send it as a reply.
- Use the **Auto-reply enabled** switch to turn replies on/off without disconnecting.
- **Stop** disconnects the bot.

## Behavior

- Listens for messages that are **replies** (Discord “reply” to another message).
- If the message being replied to was sent **by the bot** (the account whose token you use), the app:
  1. Sends the quoted text to LM Studio with a system prompt to act as an “away” auto-reply.
  2. Sends the generated text as a reply to the user.
- If LM Studio is unreachable or errors, it falls back to a fixed message: *"I'm not at my computer right now—I'll get back to you soon!"*

## Theme

- Black and white only.
- Rounded corners on cards and buttons.
- Smooth animations: window fade-in, status bar animation when connecting/generating, and smooth hover on buttons.

## Security

- Use only a **bot** token from the Developer Portal (no personal account token).
- You can set `DISCORD_AUTO_REPLY_TOKEN` in your environment and leave the token field empty so the token never appears in the app or in screenshots.
- Do not share your token or commit it.
